# Activity 3 Student Worksheet

## Command prompts

Conduct interviews for at least two prompts:

- “I want `status`.”
- “I want `diff`.”
- “I want to `add` a file.”
- “I want to `commit` my changes.”
- “I want to view the `log`.”

## Interview 1

Command: git diff
| Question | User answer |
|---|---|
| Why do you want it? | to see the line by line changes |
| What problem does it solve? | Catches accidental modifications. |
| What may happen without it? | broken code can get commited into the repo |
| What outcome do you ultimately need? | Full understanding of the changes |

**UN:** A developer needs a way to inspect line by line changes

because its helps to avoid unwanted changes to get commied.

**UR:** A developer shall be able to see the changes of their own work.

## Interview 2

Command: git log

| Question | User answer |
|---|---|
| Why do you want it? | to review the commit history |
| What problem does it solve? | verify the recent commits |
| What may happen without it? | teammates may lose the recent work without verifying the history |
| What outcome do you ultimately need? | A clear history of changes |

**UN:** A developer needs a way to see their commit history

because to verify the recent commit and look at what was the changes.

**UR:** A developer shall be able to see the recent change history to prevent them to write unwanted code.
